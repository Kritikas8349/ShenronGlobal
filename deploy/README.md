# VPS deployment for shenronglobal.ae

This project can serve the Vite build and API from one Node process. Nginx terminates HTTPS and proxies requests to Node on `127.0.0.1:5000`; MongoDB stores blog posts and contact enquiries. Keep the upload directory on persistent disk.

## Before deployment

- Point DNS for `shenronglobal.ae` and `www.shenronglobal.ae` to the VPS. Open inbound ports 80 and 443 (and SSH from a restricted IP range).
- Install Node.js 20 or newer, Nginx, Certbot with the Nginx plugin, and a supported MongoDB service. A managed MongoDB deployment is recommended; allow its network access only from the VPS.
- Create a non-root service account and persistent directories. Example paths below match the included systemd unit:

  ```sh
  sudo useradd --system --home-dir /var/lib/shenronglobal --shell /usr/sbin/nologin shenron
  sudo install -d -o shenron -g shenron /var/www/shenronglobal /var/lib/shenronglobal/uploads
  sudo install -d -o root -g shenron -m 0750 /etc/shenronglobal
  ```

## Build and configure

Deploy the repository to `/var/www/shenronglobal`, then build the frontend and install the production API dependencies:

```sh
cd /var/www/shenronglobal
npm ci
npm run build
cd backend
npm ci --omit=dev
```

Create `/etc/shenronglobal/backend.env` with mode `0640`, owned by `root:shenron`. Never put production secrets in Git or in the frontend environment. Set these values, replacing the placeholders:

```dotenv
NODE_ENV=production
PORT=5000
HOST=127.0.0.1
MONGODB_URI=<private MongoDB connection string>
CLIENT_ORIGIN=https://shenronglobal.ae,https://www.shenronglobal.ae
PUBLIC_SITE_URL=https://shenronglobal.ae
FRONTEND_DIST_DIR=/var/www/shenronglobal/dist
UPLOAD_DIR=/var/lib/shenronglobal/uploads
ADMIN_EMAIL=<admin email>
ADMIN_PASSWORD_HASH=<bcrypt hash generated by npm run hash-password>
JWT_SECRET=<random secret of at least 32 characters>
JWT_COOKIE_NAME=sg_admin_session
COOKIE_SAME_SITE=lax
COOKIE_SECURE=true
STORAGE_PROVIDER=local
SMTP_HOST=<SMTP server from your company email provider>
SMTP_PORT=587
SMTP_SECURE=false
SMTP_USER=<company email login ID>
SMTP_PASSWORD=<provider-issued SMTP password or app password>
SMTP_FROM_EMAIL=<company email address recipients should see>
SMTP_FROM_NAME=Shenron Global
```

Generate the admin bcrypt hash from `backend/` with `npm run hash-password`. Generate the JWT secret with a cryptographically secure generator, for example `openssl rand -base64 48`. Set the file permissions and ownership:

```sh
sudo chown root:shenron /etc/shenronglobal/backend.env
sudo chmod 0640 /etc/shenronglobal/backend.env
sudo chown -R shenron:shenron /var/www/shenronglobal /var/lib/shenronglobal
```

If Node is installed somewhere other than `/usr/bin/node`, edit `ExecStart` in the unit file to the system Node path. Install and start the service:

```sh
sudo install -m 0644 deploy/systemd/shenronglobal.service /etc/systemd/system/shenronglobal.service
sudo systemctl daemon-reload
sudo systemctl enable --now shenronglobal
sudo systemctl status shenronglobal
```

## Nginx and HTTPS

Install the included HTTP site config, enable it, validate Nginx, and reload:

```sh
sudo install -m 0644 deploy/nginx/shenronglobal.ae.conf /etc/nginx/sites-available/shenronglobal.ae
sudo ln -s /etc/nginx/sites-available/shenronglobal.ae /etc/nginx/sites-enabled/shenronglobal.ae
sudo nginx -t
sudo systemctl reload nginx
```

After DNS resolves to the VPS, issue and install TLS certificates:

```sh
sudo certbot --nginx --redirect -d shenronglobal.ae -d www.shenronglobal.ae
```

Certbot should configure HTTPS and renewal. Confirm `https://shenronglobal.ae/health` returns `{"status":"ok"}`, then check `/`, `/contact-us`, `/admin/login`, `/admin/enquiries`, `/blogs`, and `/sitemap.xml`. Admin session cookies are secure in production. Keep port 5000 private; only Nginx should reach it.

## Contact enquiries

Both the Contact page and portfolio enquiry popup post to `/api/enquiries`. The public API validates the fields, limits submissions, filters a hidden honeypot, and stores legitimate submissions in MongoDB. Enquiry records are private and require the admin session at `/admin/enquiries`. Admins can search/filter, save a private note and status, send a reply from the configured company mailbox, or open a prefilled WhatsApp message for review and sending.

To enable company email, fill the `SMTP_*` entries in `/etc/shenronglobal/backend.env`. Put the visible sender mailbox in `SMTP_FROM_EMAIL`, the SMTP login in `SMTP_USER`, and the provider-issued SMTP/app password in `SMTP_PASSWORD`; also enter the provider's SMTP host, port, and TLS setting. `SMTP_FROM_EMAIL` should normally be an address the authenticated SMTP mailbox is allowed to send as. Configure the sender domain's SPF/DKIM records as required by the mailbox provider for reliable delivery. Then restart with `sudo systemctl restart shenronglobal`. The admin Enquiries page shows whether the settings are complete and which sender address is active. Keep the password private; do not put it in frontend config or Git.

Back up MongoDB and `/var/lib/shenronglobal/uploads` on a schedule, test restores, update the app with a controlled release process, and monitor `journalctl -u shenronglobal` plus Nginx logs. Do not expose MongoDB, the Node port, or the environment file publicly.
